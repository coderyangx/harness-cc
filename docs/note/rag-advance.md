## RAG 下一阶段学习计划：RRF -> BM25 -> 模型回答

### Summary

接下来按“三步递进”学习，不跳知识点：

1. RRF(Reciprocal Rank Fusion) 排名融合：先学怎么把 embedding search 和 keyword search 的排名融合起来。
   - 倒数排名融合，一种混合多路检索结果的算法。
   - 核心思想：不关心原始分数的大小，只关心排名位置。
   - 优点：完全不需要归一化分数，天然解决量纲问题。

2. BM25(Best Match 25) 原理：再理解比当前 keyword count 更成熟的关键词检索算法。
   - 最佳匹配25，关键词检索领域最经典的评分算法，是 TF-IDF 的升级版，Elasticsearch 默认用它。
   - 关键改进：
     - TF 饱和：词频越高得分越高，但有上限，不会无限增长
     - 文档长度惩罚：长文档因为字数多天然包含更多词，BM25 对此做了补偿

3. 接模型回答：最后把检索结果组装成 prompt，让模型基于引用资料回答。

这样顺序最稳：先会融合，再理解关键词检索为什么要升级，最后进入完整 RAG QA。

### Rank

Rank = 排名位置，就是一个文档在某次检索结果列表里排第几。

最直接的理解：搜索"agent loop 是什么"，检索系统返回10个文档，按相关性排序：

```
排名1（rank=1）：s01_agent_loop.md ← 最相关
排名2（rank=2）：s06_context.md
排名3（rank=3）：s02_tool_use.md
排名10（rank=10）：s09_memory.md ← 最不相关

这里的 1、2、3…就是 rank。
```

#### RAG 里为什么要关心 rank

检索不只有一路，通常有两路，同一个文档在两路里的排名可能完全不同：

- 语义路（embedding 相似度）→ 产生一个排名列表
- 关键词路（BM25/TF-IDF）→ 产生另一个排名列表

```
文档"s01_agent_loop.md"：
  语义路排名：第 3
  关键词路排名：第 1
```

融合的问题：怎么把两个列表合并成一个最终排名？

#### Rank 在 RRF 里的作用

RRF 的核心思想就是：用排名位置代替原始分数

```
RRF得分 = 1/(60 + rank_语义) + 1/(60 + rank_关键词)
```

为什么用排名而不用原始分数：

```
语义分：0.82, 0.79, 0.77...   ← 都堆在 0.7~0.9，区分度小
关键词分：0.3, 12.7, 5.2...   ← 量纲完全不同，没法直接加

排名：1, 2, 3, 4, 5...        ← 天然归一，所有路都用同一把尺子
```

排名是序数（第几名），原始分是基数（多少分）。RRF 把不同量纲的基数统一转换成可比较的序数，这就是它比简单加权更稳健的原因。

直觉类比，期末考试总评，你有语文和数学两科：

- 语文满分150，你考了120
- 数学满分100，你考了85

错误做法：直接相加 120+85=205（量纲不同）
归一化：语文 120/150=0.8，数学 85/100=0.85，加权平均

**RRF 思路**：语文全班第5名，数学全班第3名 → 用排名综合评价，不管原始分是多少
